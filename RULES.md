# NARA: Rules

## Penulisan

Berlaku untuk semua teks: UI copy, dokumen (`*.md`), komentar kode, pesan commit/PR, dan jawaban chat.

- **Tanpa emoticon/emoji.** Termasuk penanda status seperti centang atau silang di tabel. Tulis statusnya dengan kata (mis. "Ya", "Tidak", "Selesai").
- **Tanpa em-dash (U+2014).** Ganti dengan titik, koma, titik dua, atau pecah jadi dua kalimat. Untuk pemisah info di UI pakai `·`. En-dash (–) untuk rentang angka (mis. `12–16`) tetap boleh.
- Ikon visual di aplikasi pakai Material Icons, bukan emoji.
